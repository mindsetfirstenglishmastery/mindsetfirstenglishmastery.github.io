# mindsetfirstenglishmastery.com

The website for Mindset-First English Mastery, hosted free on GitHub Pages.

## How it works

Every folder in here becomes a URL. The file inside is always called `index.html`.

```
index.html               ->  mindsetfirstenglishmastery.com
404.html                 ->  shown when a link is wrong
speakbold/index.html     ->  mindsetfirstenglishmastery.com/speakbold
freeze-test/index.html   ->  mindsetfirstenglishmastery.com/freeze-test
```

That is the whole rule. Folder name is the URL, file is always `index.html`.

## Adding a new page

Three ways, pick whichever suits the day.

**Ask Claude.** Paste the artifact into a chat and ask for it to go live. It builds the page and pushes it here.

**Upload it yourself on github.com.** Open this repository, click **Add file**, then **Upload files**. To put it in a folder, rename the file to `your-folder/index.html` before you drag it in and GitHub creates the folder for you.

**Build it first in Publish Studio.** That tool adds the brand fonts, the page title, the search description and the share card, then gives you a finished `index.html` to upload.

Changes go live about a minute after they are saved here.

## Do not delete

- `CNAME` holds the custom domain. If this file disappears, the site drops back to the github.io address and the custom domain has to be set up again.

## Linking a new page from the homepage

Open `index.html` and find the block marked `TOOL CARDS GO HERE`. Copy the commented pattern, fill in the folder name, the title and one line of description. The placeholder message below the cards hides itself once a real card is there.
